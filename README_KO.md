# Vyact — 내 데이터와 웹을 연결하는 로컬 AI 워크스페이스

### 로컬 AI를, 실제로 쓰는 도구로.

Vyact는 내 컴퓨터의 AI를 문서·메일·코드와 연결하고, 크롬에서 글쓰기·웹 탐색·언어 학습에 활용하는 데스크톱 앱입니다. 자료를 매번 복사해 설명하는 수고를 줄이고, 답변의 근거와 수정 결과를 확인하며 다음 작업으로 이어갈 수 있습니다.

## 해결하려는 문제

로컬 모델을 실행해도 실제 작업에 쓰려면 준비가 필요합니다. 문서와 메일을 대화에 옮기고, 웹에서 읽은 내용을 다시 설명하고, 생성된 답이나 수정안을 원문과 비교해야 합니다. 작업이 바뀔 때마다 이 과정도 반복됩니다.

Vyact는 **모델 실행 → 필요한 자료 연결 → AI 작업 → 근거와 변경 확인**을 하나의 사용 흐름으로 구성했습니다.

| 작업에서 겪는 불편 | Vyact의 접근 |
| --- | --- |
| 내 자료를 질문할 때마다 다시 찾아 붙여 넣어야 함 | 문서·메모·이메일을 검색 가능한 지식으로 저장하고, 필요한 자료 묶음을 선택 |
| AI가 제안한 답변이나 수정의 근거를 확인하기 어려움 | 답변의 원문 구간, 글쓰기 전후 비교, 코드 변경 내역을 확인할 수 있게 제공 |
| 글쓰기·웹 탐색·언어 학습마다 별도 도구로 이동함 | 크롬의 현재 페이지·입력창·자막에서 AI를 사용하고 학습한 표현을 저장 |
| 로컬 모델 선택과 실행 준비가 복잡함 | 앱 안에서 모델 검색·메모리 예상량 비교·다운로드·런타임 준비를 연결 |

문서와 메일을 자주 다루는 개인 사용자, 외국어로 읽고 쓰는 학습자, 자신의 프로젝트에 로컬 AI를 활용하려는 개발자를 위한 도구입니다.

## 데모와 첫 체험

[![모델 성능 테스트·문서 질문·메일 답장·브라우저 교정 통합 데모](assets/readme/demo-complete-showcase.png)](https://youtu.be/V3NTHU94lP8)

**3분 29초 통합 데모**에서 모델 선택과 성능 테스트, 문서 질의응답과 원문 근거 확인, 이메일 서명과 AI 답장 작성, 브라우저 교정 제안의 적용을 볼 수 있습니다. 가상의 자료를 사용한 실제 앱 녹화이며, 대기 구간을 편집했고 문서 답변 생성 일부는 2배속입니다. MLX는 Apple Silicon Mac에서 사용할 수 있으며, 성능 테스트 결과는 하드웨어·모델·설정에 따라 달라집니다.

직접 사용하려면 [앱을 설치](#설치-안내)하고 모델 준비가 끝난 뒤, 아래 중 한 가지부터 시작하세요. 메일 계정 연결 없이도 문서 질문과 크롬 기능을 체험할 수 있습니다.

| 체험 | 해볼 작업 | 확인할 결과 |
| --- | --- | --- |
| 문서에서 답 찾기 | PDF를 첨부하고 “핵심 내용 3개와 근거가 되는 원문을 알려줘”라고 질문 | 답변의 출처를 열어 원문과 비교 |
| 브라우저 글쓰기 | 지원되는 웹 편집기에 `회의 자료를 검토한 후 의견을 보내주시면 감사하겟습니다.`를 입력하고 검사 | 밑줄과 수정 제안을 확인한 뒤 원하는 변경만 적용 |
| 웹페이지 읽기 | 기사를 열고 사이드 패널에서 페이지 요약 요청 | 요약을 읽고 같은 페이지에 대해 후속 질문 |
| 코드 작업 | 프로젝트에 작업 폴더를 연결하고 “집중 타이머를 HTML 파일로 만들어줘”라고 요청 | 생성된 파일과 변경 내역을 리뷰하고 결과 확인 |

첫 다운로드와 실행 준비에는 인터넷 연결·저장 공간·시간이 필요합니다. 답변 속도와 품질, 도구 실행 성공 여부는 모델·하드웨어·설정에 따라 달라집니다.

## 주요 활용

### 자신 있게 써 내려가세요

![입력 중 문법 오류를 확인하고 원하는 수정만 적용하는 Vyact 글쓰기 도우미](assets/readme_ko/feature-01-live-writing-ko-1280x720.png)

크롬의 지원되는 웹 편집기에서 글을 쓰면 맞춤법·문법·띄어쓰기·문장부호를 검사합니다. 밑줄로 표시된 부분을 눌러 변경 내용을 확인하고, 제안을 개별 또는 한꺼번에 적용하거나 무시할 수 있습니다. 단어 제안과 수정 이유는 기본적으로 꺼져 있으며 필요할 때 켤 수 있습니다. **사용자가 적용하기 전에는 원문을 바꾸지 않습니다.**

- **자동 검사:** 검사 설정에서 켜고 끄며, 모든 사이트에 공통으로 적용됩니다. 켜두면 입력을 잠시 멈췄을 때 최신 내용을 검사하며, 검사 중 글을 고치면 이전 요청을 취소합니다.
- **사이트별 사용 중지:** 도구 모음의 전원 버튼으로 해당 사이트에서 글쓰기 도구 자체를 끌 수 있습니다. 자동 검사와는 별개의 설정입니다.
- **글 다듬기:** 입력창 전체를 자연스럽게·정중하게·간결하게·유머러스하게 다듬거나 문법을 교정합니다. 출력 언어와 추가 지시도 지정할 수 있습니다.
- **전후 비교:** 원문과 결과를 나란히 확인한 뒤 지원되는 편집기에 적용하거나 복사합니다.

### 넷플릭스로 즐기는 언어 학습

![영어 원문과 한국어 보조 자막, 반복 재생과 AI 표현 설명을 제공하는 Netflix 학습 화면](assets/readme_ko/feature-03-netflix-learning-ko-1280x720.png)

넷플릭스 재생 페이지에서 Vyact 학습 뷰어를 열면 원문과 보조 자막을 함께 볼 수 있습니다. 문장별로 이동하거나 한 줄을 다시 듣고, 자동 일시정지로 듣기 연습을 이어갑니다.

현재 자막의 뜻이나 문법이 궁금하면 사이드 패널에서 질문하세요. 장면의 표현을 이해하고 반복해서 듣는 흐름을 한 화면에서 이어갈 수 있습니다.

### 긴 페이지도, 핵심은 한눈에

![영어 웹페이지의 핵심을 한국어로 요약하고 후속 질문을 이어가는 Vyact 사이드 패널](assets/readme_ko/feature-04-page-summary-ko-1280x720.png)

현재 페이지나 선택한 문장을 AI 대화에 보내 요약과 설명을 요청합니다. 웹페이지를 별도로 복사하지 않고, 읽던 내용을 바탕으로 후속 질문을 이어갈 수 있습니다.

선택한 글을 빠르게 번역하거나 사이드 패널에서 자세히 확인하고, 읽기 모드로 본문이나 선택 문단을 번역할 수 있습니다. 단어의 뜻·발음·예문을 살펴보고 유용한 표현은 단어장에 저장합니다.

### 아이디어를 코드로, 변경 사항은 한눈에

![AI가 생성한 HTML 파일과 파일별 변경 내역을 확인하는 Vyact 코드 리뷰 화면](assets/readme_ko/feature-coding-ko-1280x720.png)

프로젝트에 작업 폴더를 연결한 뒤 만들고 싶은 기능을 대화로 설명하고, 생성·편집된 코드와 파일별 변경 내용을 확인합니다. 변경된 파일 목록에서 리뷰를 열어 추가·삭제된 줄을 살펴보고, 결과를 복사하거나 다운로드할 수 있습니다.

파일 검색·수정과 프로젝트 검사도 요청할 수 있습니다. 실행 가능한 도구는 선택한 모델과 도구 설정에 따라 달라집니다.

### 메일·파일·일정도 한곳에서

![Gmail, Google Drive, Google Calendar를 함께 관리하는 Vyact Google 연동 화면](assets/readme_ko/feature-google-1280x720.png)

Google 계정을 연결하면 Gmail·Drive·Calendar를 대화 옆에서 사용합니다. 메일을 읽고 답장 초안을 만들거나, 관련 파일을 대화에 연결하고 일정을 확인할 수 있습니다. Microsoft 계정으로 Outlook·OneDrive·일정도 연결할 수 있습니다.

연동은 선택 사항입니다. **설정 > Google**에서는 OAuth 자격증명 JSON을, **설정 > Microsoft**에서는 Microsoft Entra 앱의 Client ID를 등록하고 각 화면의 사전 설정 가이드를 따라 로그인하세요. Microsoft 앱 등록 권한이나 회사·학교 계정의 관리자 동의가 필요할 수 있습니다.

연결한 계정은 하나의 목록에서 전환합니다. **Cmd+Shift+G**(Mac) 또는 **Ctrl+Shift+G**(Windows)로 메일·파일·일정 패널을 열고 닫습니다.

### 내 컴퓨터에 맞는 AI, 직접 고르세요

![메모리 정보와 모델 사양을 비교해 GGUF 또는 MLX 모델을 다운로드하는 화면](assets/readme_ko/feature-model-ko-1280x720.png)

앱 안에서 로컬 모델을 검색하고, 모델 크기·양자화 방식·최대 컨텍스트와 컴퓨터 메모리 정보를 비교합니다. 원하는 모델을 다운로드하면 Vyact가 필요한 로컬 런타임을 준비합니다.

- **Mac:** Apple Silicon에서 GGUF와 MLX 모델을 사용할 수 있습니다.
- **Windows·Linux:** GGUF 모델을 사용할 수 있습니다.
- **모델 접근:** 공개 모델은 API 키 없이 이용할 수 있으며, 접근 승인이 필요한 모델은 권한이 있는 Hugging Face 계정의 키가 필요합니다.
- **성능 비교:** 모델 설정의 성능 테스트에서 지원되는 설정 조합의 응답 시간과 생성 속도를 비교하고 적용할 수 있습니다. 속도 비교 결과는 답변 품질 점수가 아닙니다.

이미지의 메모리 수치는 예시 환경의 값입니다. 실행 가능 여부와 속도는 내 컴퓨터의 메모리, 선택한 모델과 설정에 따라 달라집니다.

| 글쓰기 검사·다듬기 | 오류 밑줄, 개별·일괄 적용·무시·되돌리기, 문체·출력 언어·추가 지시를 반영한 전후 비교 |
| 단어장·문장 보관함 | 뜻·발음·예문 확인, 단어와 번역 문장을 출처와 함께 저장·검색·듣기·삭제 |
| Netflix 자막 학습 | 이중 자막, 문장 이동·반복·자동 일시정지, 전체 스크립트 탐색 |
| 약점에 맞춘 표현 설명 | 언어별 숙어·연결음·문법·뉘앙스 등 학습 초점 선택, 자막·표현 질문과 문장 저장 |
| AI 작품 찾기 | 기억나는 줄거리나 보고 싶은 내용을 설명해 작품 후보를 받고 Netflix 검색으로 이동 |
| 데스크톱 AI의 브라우저 연결 | Vyact의 브라우저 작업을 Chrome에서 실행하고 페이지의 동작 확인 |

크롬 확장은 실행 중인 Vyact 데스크톱 앱과 함께 사용합니다. 글쓰기 기능은 지원되는 웹 편집기에서 동작하며, Netflix 학습은 작품에서 제공하고 불러온 자막 트랙에 따라 달라집니다. AI 작품 후보가 해당 지역의 실제 제공 목록을 보장하지는 않습니다.

## AI를 어떻게 활용하나요

Vyact의 핵심은 **선택한 모델에 작업에 필요한 맥락을 전달하고, 결과를 사용자가 확인·활용할 수 있는 기능으로 연결하는 것**입니다.

| 단계 | 구현 방식 |
| --- | --- |
| 모델 실행 | Hugging Face에서 GGUF·MLX 모델을 검색하고 llama.cpp·llama-swap 또는 Apple Silicon용 oMLX로 실행. 외부 AI와 OpenAI 호환 서버도 선택 가능 |
| 필요한 자료 찾기 | 문서·메모 등에서 텍스트를 추출하고 임베딩·Elasticsearch 검색·리랭킹을 활용해 질문과 관련된 내용을 모델에 전달 |
| 작업에 맞는 요청 구성 | 메일 원문, 웹페이지, 입력 중인 글, 현재 자막, 프로젝트 파일 등 사용자가 선택한 작업의 맥락을 구성 |
| 도구로 작업 수행 | 지원 모델의 도구 호출을 Google·Microsoft API, 파일·브라우저 도구, MCP와 연결 |
| 결과 확인 | 검색한 원문, 교정 전후, 이메일 초안, 코드 변경 내역을 표시해 사용자가 확인하고 적용할 수 있게 제공 |

크롬 확장과 데스크톱은 같은 모델을 활용할 수 있습니다. 작은 모델도 실제 작업에 활용할 수 있도록 필요한 자료와 도구를 연결하는 구조이며, 모델 자체의 추론·언어 능력을 대체하거나 모든 결과의 정확성을 보장하는 것은 아닙니다.

### 개발 과정의 AI 활용

기능 구현·리팩터링·오류 진단·테스트·다국어 문구와 기술 문서 작성·변경 사항 검토에 **OpenAI Codex**를 활용했습니다. 제품 안에서 실행하는 AI와 개발을 돕는 AI 도구의 역할은 구분됩니다. 사용자는 Codex 계정 없이 Vyact에 로컬 모델을 연결해 사용할 수 있습니다.

## 설치 안내

> **Apple Silicon Mac(M1 이상)·Windows·Linux x64를 지원합니다. Intel Mac은 현재 지원하지 않습니다.**

### 1. 데스크톱 앱 설치

아래 버튼을 눌러 운영체제에 맞는 최신 설치 파일을 다운로드하세요.

<div align="center">

[![Vyact 최신 버전 다운로드](https://img.shields.io/badge/Vyact_최신_버전-다운로드-E27E5C?style=for-the-badge&logo=github&logoColor=white)](https://github.com/vyact/vyact/releases/latest)

- **Mac:** Apple Silicon(M1 이상)용 설치 파일을 다운로드합니다.
- **Windows:** EXE 설치 파일을 다운로드합니다.
- **Linux x64:** AppImage 또는 DEB 패키지를 다운로드합니다.
- 설치 후 Vyact를 실행하고 초기 설정에서 **Vyact 로컬 모델** 또는 사용할 AI 제공자를 선택합니다. 아래는 로컬 모델로 시작하는 순서입니다.
- 모델 검색 화면에서 내 컴퓨터의 메모리와 예상 사용량을 확인합니다.
- Mac에서는 GGUF 또는 MLX 모델을, Windows·Linux에서는 GGUF 모델을 선택해 다운로드합니다.
- 다운로드가 끝나면 Vyact가 로컬 런타임을 준비하고 선택한 모델을 실행합니다.

### 로컬 모델 실행을 위한 준비

#### Mac: 자동 런타임 설치를 위한 Homebrew 준비

Apple Silicon Mac에서 로컬 모델용 런타임을 자동으로 준비하려면 Homebrew 사용을 권장합니다. 필요한 런타임이 아직 없다면 터미널을 열고 아래 명령으로 먼저 설치하세요.

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

설치 여부는 다음 명령으로 확인할 수 있습니다.

```bash
brew --version
```

#### Windows: winget 확인

Windows에서 누락된 로컬 GGUF 런타임을 자동 설치할 때는 `winget` 사용을 권장합니다. 호환되는 런타임이 이미 설치되어 있다면 이를 사용할 수 있습니다.

```powershell
winget --version
```

#### Linux: AppImage 또는 DEB 실행

Linux x64는 glibc 2.35 이상의 데스크톱 환경이 필요합니다. CPU 런타임을 포함하며, 호환되는 GPU 런타임이 이미 설치되어 있다면 사용할 수 있습니다.

AppImage를 내려받은 폴더에서 실행합니다.

```bash
chmod +x Vyact-*.AppImage
./Vyact-*.AppImage
```

Ubuntu·Debian 계열에서는 DEB를 설치한 뒤 앱 메뉴에서 실행할 수 있습니다.

```bash
sudo apt install ./vyact_*_amd64.deb
```

문서 검색용 Elasticsearch는 앱에서 네이티브 실행을 준비할 수 있어 Docker가 필수는 아닙니다. 추가 기능에 필요한 시스템 구성 요소가 없으면 별도 설치가 필요할 수 있습니다.

</details>

브라우저에서 페이지 분석·번역과 넷플릭스 언어 학습을 체험하려면 크롬 확장 기능을 설치하세요.

> 크롬 확장의 전체 기능을 이용하려면 Vyact 데스크톱 앱이 실행 중이어야 합니다.

## AI 제공자와 데이터 처리

로컬 모델 외에도 OpenAI, Gemini, Claude와 OpenAI 호환 API 서버를 연결할 수 있습니다. 사용자 지정 서버는 초기 설정의 **Custom LLM** 또는 사이드바의 제공자 관리에서 연결합니다. `/chat/completions`를 제외한 Base URL, 정확한 모델 ID, 필요한 API 키와 추가 헤더를 입력하세요. 이미지 입력·스트리밍·도구 호출 지원은 서버와 모델에 따라 달라집니다.

크롬 확장은 데스크톱 앱에 연결해 요청한 기능에 필요한 페이지·입력·자막 내용을 전달합니다. 자동 글쓰기 검사를 켜면 입력을 잠시 멈출 때 지원되는 편집기의 텍스트를 전달합니다. 로컬 모델을 선택하면 해당 AI 처리를 내 컴퓨터에서 수행하며, 외부 AI 제공자를 선택하면 요청에 필요한 내용이 해당 제공자로 전송될 수 있습니다.

메일·클라우드 파일 연동은 각 서비스와 통신합니다. 로컬 AI 사용과 외부 서비스 연결 여부는 별도로 선택할 수 있습니다.
