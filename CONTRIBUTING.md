# Contributing to Vyact

Thank you for your interest in Vyact!

At this stage, Vyact is primarily developed and maintained by the project owner.

## Feedback Welcome

Feedback is highly appreciated, including:

- UI / UX suggestions
- Feature ideas
- Workflow improvements
- Documentation improvements
- Bug reports
- Performance suggestions

Please use GitHub Issues to share your ideas.

## Pull Requests

Currently, **code contributions are not being accepted**.

This helps keep the project architecture consistent while Vyact is under active development.

If you have an idea or improvement, please open an Issue first.

## Bug Reports

When reporting a bug, please include:

- Operating system
- Application version
- Steps to reproduce
- Expected behavior
- Actual behavior
- Screenshots (if applicable)

## Feature Requests

Feature requests are always welcome.

Please describe:

- The problem
- Your proposed solution
- Why it would improve Vyact

## Security

Please do not report security vulnerabilities through public GitHub Issues.

See `SECURITY.md` for responsible disclosure instructions.

Thank you for helping improve Vyact.
