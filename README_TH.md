## พื้นที่ทำงานเดียวสำหรับงานประจำวัน

### ค้นหาคำตอบและตรวจสอบแหล่งที่มา

แนบ PDF ในแชตแล้วถามถึงการตัดสินใจสำคัญ ประเด็นที่ยังไม่ชัดเจน หรือขั้นตอนถัดไป เปิดแหล่งข้อมูลของคำตอบเพื่อตรวจสอบกับต้นฉบับ และทำดัชนีเอกสารที่ใช้บ่อยเพื่อถามอีกครั้งโดยไม่ต้องแนบไฟล์เดิมซ้ำ

**ลองใช้:** “เอกสารนี้มีความเสี่ยงหลักสามข้ออะไรบ้าง พร้อมแสดงข้อความที่สนับสนุนคำตอบ”

### เปลี่ยนอีเมลที่ได้รับเป็นร่างคำตอบที่พร้อมนำไปใช้

อ่านชุดข้อความ Gmail หรือ Outlook ข้างบทสนทนา เพิ่มไฟล์ที่เกี่ยวข้อง แล้วให้ AI ช่วยร่างคำตอบ ตรวจดูฉบับร่าง แทรกลงในช่องเขียนอีเมล และแก้ไขก่อนส่ง

**ลองใช้:** “ร่างคำตอบสั้น ๆ เพื่อยืนยันขั้นตอนถัดไปและสอบถามกำหนดส่ง”

การเชื่อมต่อ Google และ Microsoft เป็นทางเลือกและต้องตั้งค่าแอป OAuth ก่อน หากต้องการลองโดยยังไม่เชื่อมต่อบัญชี ให้เริ่มจากเอกสารในเครื่อง

### ปรับปรุงงานเขียนโดยไม่ออกจากหน้าเว็บ

ตรวจการสะกดและไวยากรณ์ขณะเขียนโพสต์ อีเมล หรือความคิดเห็น เปิดคำแนะนำที่ขีดเส้นใต้เพื่อดูตัวอย่าง แล้วเลือก **ใช้** หรือ **ละเว้น** หากเขียนใหม่ทั้งฉบับ ให้เปรียบเทียบกับต้นฉบับก่อนนำไปใช้

**ต้องติดตั้งส่วนขยาย Chrome และเปิดแอป Vyact บนเดสก์ท็อปไว้** ในช่องเขียนบนเว็บที่รองรับ คุณเลือกได้ว่าจะใช้คำแนะนำใด ข้อความต้นฉบับจะไม่เปลี่ยนจนกว่าคุณจะกดใช้

## เริ่มจากเอกสารหนึ่งฉบับ

1. [ดาวน์โหลด Vyact](https://github.com/vyact/vyact/releases/latest) ติดตั้งและเปิดแอป
2. เลือก **Vyact** เพื่อใช้โมเดลบนเครื่อง ใช้ค่าหน่วยความจำโดยประมาณและคำอธิบายสีช่วยเลือกโมเดล ดาวน์โหลดและรอให้ตั้งค่าเสร็จ หรือเลือกผู้ให้บริการ AI ที่ใช้อยู่แล้ว
3. แนบ PDF ในแชตแล้วถามว่า **“สรุปประเด็นหลักสามข้อ พร้อมแสดงข้อความที่สนับสนุนคำตอบ”**
4. เปิดแหล่งข้อมูลของคำตอบแล้วตรวจสอบกับเอกสารต้นฉบับ

การดาวน์โหลดและตั้งค่าครั้งแรกต้องใช้เวลาและอินเทอร์เน็ต ความเร็วในการตอบขึ้นอยู่กับฮาร์ดแวร์และโมเดล งานแรกนี้ไม่จำเป็นต้องเชื่อมต่ออีเมลหรือติดตั้งส่วนขยาย Chrome

[ข้อกำหนดและวิธีติดตั้งสำหรับแต่ละแพลตฟอร์ม](#การติดตั้งและการเชื่อมต่อ)

## พื้นที่ทำงานบนเดสก์ท็อป

เก็บเอกสาร บทสนทนา และเครื่องมือไว้ด้วยกัน เริ่มจากงานหนึ่งอย่าง แล้วเพิ่มการเชื่อมต่อและความสามารถที่ต้องการ

| คุณสมบัติ | สิ่งที่ทำได้ |
| --- | --- |
| **AI แชตและประวัติสนทนา** | สนทนากับโมเดลบนเครื่องหรือคลาวด์ แนบไฟล์และภาพที่รองรับ กลับไปอ่านหรือบันทึกบทสนทนาที่ชอบ ดูสถิติการตอบ และส่งออกบทสนทนา |
| **เอกสารและการตรวจสอบแหล่งที่มา** | ถามเกี่ยวกับไฟล์ PDF, Word, ตารางคำนวณ, งานนำเสนอ, Markdown และข้อความ ทำดัชนีเอกสารที่ใช้บ่อย ตรวจข้อความที่ค้นคืน และจัดการไฟล์ที่บันทึกไว้ |
| **คอลเลกชันความรู้** | รวมเอกสาร โน้ต และชุดอีเมลที่ทำดัชนีแล้ว กำหนดคำสั่งเฉพาะคอลเลกชัน และเลือกเพื่อจำกัดคำถามให้อยู่ในข้อมูลที่ต้องการ |
| **โปรเจกต์และความจำของโปรเจกต์** | จัดกลุ่มบทสนทนา ตั้งคำสั่งการทำงาน และเชื่อมโฟลเดอร์โค้ด ตรวจและจัดการสรุป การตัดสินใจ และงานที่ต้องทำซึ่งสกัดจากบทสนทนา |
| **โน้ตและงานที่ต้องทำ** | เขียนโน้ตที่มีตาราง รายการ ภาพ และบล็อกโค้ด ค้นโน้ตด้วย RAG และติดตามสถานะเสร็จของงานสั้น ๆ |
| **งานอีเมล** | อ่าน ค้นหา ตอบ และส่งต่อใน Gmail หรือ Outlook ดูร่างจาก AI ก่อนใช้ จัดการไฟล์แนบ ลายเซ็น ข้อความที่ใช้ซ้ำ และกลุ่มผู้รับ |
| **ไฟล์คลาวด์และปฏิทิน** | อัปโหลด ดาวน์โหลด จัดระเบียบ และแชร์ไฟล์ Google Drive หรือ OneDrive แล้วแนบเข้าแชตหรือทำดัชนี สร้างและแก้ไขกิจกรรม Google หรือ Microsoft |
| **Google Docs, Sheets, Slides และ Forms** | ให้ AI สร้างหรือแก้เอกสาร Google อ่านและแก้เซลล์ตาราง เปลี่ยนสไลด์ สร้างแบบฟอร์ม และอ่านคำตอบ |
| **งานโค้ดและรีวิวการแก้ไข** | เชื่อมโฟลเดอร์โปรเจกต์ ให้ AI ค้นและแก้ไฟล์ รันการตรวจสอบที่โปรเจกต์มี และดูการเปลี่ยนแปลง Git ตรวจส่วนต่างของไฟล์ คัดลอกหรือดาวน์โหลดผลลัพธ์ และย้อนการแก้ไขที่ติดตามไว้ |
| **งานในเบราว์เซอร์** | ให้ AI ค้นเว็บ อ่านหน้า และใช้งานส่วนควบคุมที่มองเห็น ต่อจากผลการค้นหาไปยังหน้าและการดำเนินการที่งานต้องการได้ |
| **เสียงและฝึกสนทนา** | พูดกับ AI ฟังคำตอบ และปรับการเล่นเสียง สร้างหรือแก้บทฝึก เลือกบทบาท ฟังคู่สนทนา และฝึกพูดส่วนของคุณ |
| **การปรับให้เหมาะกับคุณและพรอมป์ต์** | เลือกรูปแบบการตอบ ตรวจโปรไฟล์ส่วนตัวที่ AI สร้างก่อนนำไปใช้ และบันทึกพรอมป์ต์ระบบหรือสกิลที่ใช้ซ้ำ |
| **โมเดลที่เหมาะกับคอมพิวเตอร์** | ค้นและดาวน์โหลด GGUF หรือ MLX สำหรับ Apple Silicon เปรียบเทียบหน่วยความจำโดยประมาณ เลือกที่เก็บ และทดสอบการตั้งค่าที่รองรับบนเครื่องจริง |
| **เครื่องมือ MCP และ API บนเครื่อง** | เชื่อม MCP ในเครื่องหรือระยะไกล เลือกเครื่องมือสำหรับแต่ละคำขอ และจัดการการอนุมัติ ใช้โมเดลบนเครื่องที่กำลังทำงานจากแอปอื่นผ่าน API ที่รองรับ OpenAI |
| **สำรองข้อมูลและการใช้งานประจำวัน** | สำรองและกู้คืนข้อมูลที่เลือกในเครื่องหรือผ่าน Drive และ OneDrive สลับบัญชี ดูการแจ้งเตือน ใช้ปุ่มลัด ธีมสว่าง/มืด และ UI แปดภาษา |

การเชื่อมต่อ Google และ Microsoft ต้องตั้งค่าบัญชีและสิทธิ์ การทำงานของ AI ขึ้นกับความสามารถเรียกเครื่องมือของโมเดลและบริการที่เชื่อมต่อ เครื่องมือของทั้งสองบริการไม่เหมือนกันทั้งหมด

## Vyact สำหรับ Chrome มีมากกว่าแชตด้านข้าง

ใช้ AI บนหน้าที่กำลังอ่านหรือเขียน **ติดตั้งส่วนขยาย Chrome และเปิดแอป Vyact บนเดสก์ท็อปไว้** เพื่อเชื่อมเครื่องมือเหล่านี้กับโมเดลที่เลือก

| คุณสมบัติ | สิ่งที่ทำได้ |
| --- | --- |
| **แชตข้างหน้าเว็บที่รองรับ** | ถามต่อในแผงด้านข้าง เพิ่มภาพหรือไฟล์ เลือกพรอมป์ต์ที่บันทึก และกลับไปดูประวัติสนทนา |
| **ถาม สรุป และบันทึกหน้าเว็บ** | เพิ่มหน้าปัจจุบันหรือข้อความที่เลือกเข้าแชต สรุปหน้า หรือบันทึกลง Vyact เพื่อค้นความรู้ภายหลัง |
| **การแปลและโหมดอ่าน** | แปลข้อความที่เลือกอย่างรวดเร็วหรือเปิดคำแปลละเอียด แปลย่อหน้าหรือส่วนที่เลือกในโหมดอ่าน และฟังข้อความที่เลือก |
| **ตรวจงานเขียนขณะพิมพ์** | ดูข้อเสนอการสะกดและไวยากรณ์จากเส้นใต้ ตรวจ ใช้ หรือละเว้นทีละรายการหรือทั้งหมด และย้อนการแก้ไขได้ |
| **ปรับร่างทั้งฉบับ** | ทำให้ข้อความเป็นธรรมชาติ สุภาพ กระชับ หรือตลกขึ้น หรือแก้ไวยากรณ์ เลือกภาษา เพิ่มคำสั่ง และเปรียบเทียบก่อนใช้หรือคัดลอก |
| **ตั้งค่าเครื่องมือเขียน** | เปิดหรือปิดการตรวจอัตโนมัติ เปิดคำแนะนำคำและเหตุผลการแก้ไขเมื่อต้องการ โดยทั้งสองอย่างปิดไว้ตามค่าเริ่มต้น ปรับเครื่องมือเขียนและเครื่องมือข้อความที่เลือกให้เหมาะกับหน้าเว็บได้ |
| **คำศัพท์และประโยคที่บันทึก** | ค้นความหมายและการออกเสียง เก็บคำพร้อมประโยคตัวอย่าง บันทึกประโยคพร้อมคำแปลและลิงก์ต้นทาง ค้น ฟัง หรือลบรายการได้ |
| **ฝึกฟังด้วย Netflix** | เรียนด้วยสองแทร็กคำบรรยาย เลื่อนไปแต่ละประโยค ฟังซ้ำ วนซ้ำ และหยุดอัตโนมัติ เปิดสคริปต์คำบรรยายทั้งหมดแล้วเลือกประโยคเพื่อข้ามไปได้ |
| **คำอธิบาย Netflix ตามจุดที่อยากฝึก** | ถามเกี่ยวกับคำบรรยายปัจจุบันหรือสำนวนที่เลือก ตั้งจุดเน้นรายภาษา เช่น สำนวน เสียงเชื่อม ไวยากรณ์ หรือนัยของคำ และบันทึกประโยคที่มีประโยชน์ |
| **ค้นหาผลงาน Netflix ด้วย AI** | บรรยายเรื่องราวหรือสิ่งที่อยากดู ตรวจชื่อที่แนะนำพร้อมเหตุผล แล้วเปิดการค้นหา Netflix สำหรับเรื่องที่สนใจ |

### ติดตั้งแอปเดสก์ท็อป

ดาวน์โหลดสำหรับ **Mac แบบ Apple Silicon (M1 ขึ้นไป)**, **Windows** หรือ **Linux x64** จาก [GitHub Releases](https://github.com/vyact/vyact/releases) แล้วติดตั้งและเปิดแอป macOS ใช้ DMG, Windows ใช้ตัวติดตั้ง EXE และ Linux มี AppImage และ DEB ปัจจุบันยังไม่รองรับ Mac ที่ใช้ Intel

#### ใช้งานบน Linux

AppImage เปิดได้โดยไม่ต้องติดตั้ง จากโฟลเดอร์ที่ดาวน์โหลดไฟล์ ให้เรียกใช้:

```bash
chmod +x Vyact-*.AppImage
./Vyact-*.AppImage
```

บน Ubuntu, Debian หรือระบบที่เข้ากันได้ สามารถติดตั้ง DEB แทนได้:

```bash
sudo apt install ./vyact_*_amd64.deb
```

หลังติดตั้ง DEB ให้เปิด **Vyact** จากเมนูแอปพลิเคชัน

### ก่อนเปิดใช้งานครั้งแรก

Vyact มี Python ในตัวและเตรียมส่วนประกอบที่จำเป็นตามการตั้งค่าที่เลือก Homebrew บน macOS และ `winget` บน Windows ช่วยติดตั้งส่วนที่ขาด แพ็กเกจ Linux มีรันไทม์ CPU และใช้รันไทม์ GPU ที่ติดตั้งไว้แล้วและเข้ากันได้ได้เช่นกัน

| แพลตฟอร์ม | สิ่งที่แอปหลักต้องใช้ | ข้อกำหนดตามคุณสมบัติ |
| --- | --- | --- |
| macOS (Apple Silicon) | ไม่มี | **GGUF บนเครื่อง**: แนะนำ [Homebrew](https://brew.sh/) เพื่อติดตั้งโปรแกรมที่ขาด หรือใช้ `llama-server` และ `llama-swap` ที่เข้ากันได้<br><br>**MLX บนเครื่อง**: แนะนำ Homebrew เพื่อติดตั้งหรืออัปเดต oMLX อัตโนมัติ หรือใช้ `omlx` ที่เข้ากันได้<br><br>**Elasticsearch**: โหมดรันโดยตรงไม่ต้องใช้ส่วนพึ่งพาภายนอก ส่วน Docker Desktop เป็นทางเลือกสำหรับโหมดคอนเทนเนอร์<br><br>**Kokoro TTS**: ต้องใช้ Homebrew เฉพาะเมื่อต้องติดตั้ง `espeak-ng` |
| Windows | ไม่มี | **GGUF บนเครื่อง**: แนะนำ `winget` เพื่อติดตั้งโปรแกรมที่ขาด หรือใช้ `llama-server` และ `llama-swap` ที่เข้ากันได้<br><br>**Elasticsearch**: โหมดรันโดยตรงไม่ต้องใช้ส่วนพึ่งพาภายนอก Docker Desktop เป็นทางเลือก<br><br>**Kokoro TTS**: ต้องใช้ `winget` เฉพาะเมื่อต้องติดตั้ง `espeak-ng` |
| Linux (x64) | เดสก์ท็อป x86-64 ที่ใช้ glibc 2.35 ขึ้นไป โดย DEB ติดตั้งไลบรารีเดสก์ท็อปที่ประกาศไว้ผ่าน APT | **GGUF บนเครื่อง**: มีรันไทม์ CPU ไม่ต้องใช้ Homebrew<br><br>**Elasticsearch**: โหมดรันโดยตรงไม่ต้องใช้ส่วนพึ่งพาภายนอก Docker เป็นทางเลือก<br><br>**เบราว์เซอร์และ Kokoro TTS**: หากขาดไลบรารีหรือ `espeak-ng` ต้องมีตัวจัดการแพ็กเกจที่รองรับ (`apt-get`, `dnf`, `zypper`, `pacman`) และตัวแทนยืนยันตัวตน PolicyKit บนเดสก์ท็อป Vyact ขอสิทธิ์ผ่าน `pkexec`; หากไม่มี จะลองเฉพาะ `sudo` ที่ไม่ต้องใช้รหัสผ่านหรือมีการยืนยันตัวตนที่ยังใช้ได้ |

Docker เป็นทางเลือก เพราะ Vyact ดาวน์โหลดและรัน Elasticsearch รุ่นที่รองรับโดยตรงเพื่อค้นฐานความรู้ได้ ตัวจัดการแพ็กเกจจำเป็นเฉพาะเมื่อคุณสมบัติที่เลือกขาดส่วนประกอบระบบ

### เชื่อมต่อผู้ให้บริการ LLM แบบกำหนดเอง

Vyact เชื่อมกับเซิร์ฟเวอร์ที่รองรับ API `/chat/completions` แบบ OpenAI ได้ เลือก **Custom LLM** ระหว่างตั้งค่าเริ่มต้น หลังติดตั้งแล้วเพิ่มหรือแก้ไขการเชื่อมต่อจากส่วนผู้ให้บริการในแถบด้านข้างได้

- **ชื่อการเชื่อมต่อ** — ชื่อที่แสดงใน Vyact
- **Base URL** — ที่อยู่หลัก API โดยไม่รวม `/chat/completions` เช่น `http://localhost:11434/v1`
- **คีย์ API** — ไม่บังคับสำหรับเซิร์ฟเวอร์ในเครื่อง แต่จำเป็นหากใช้การยืนยันตัวตนแบบ Bearer
- **Model ID** — รหัสโมเดลที่ตรงกับที่ API ต้องการ
- **ส่วนหัวเพิ่มเติม** — สำหรับเกตเวย์หรือการยืนยันตัวตนเฉพาะองค์กร

ตัวอย่างการเชื่อมต่อเซิร์ฟเวอร์ในเครื่องที่รองรับ OpenAI ซึ่งมีอยู่แล้ว:

```text
Connection name: Local LLM
Base URL: http://localhost:8080/v1
API key: (leave blank)
Model ID: my-local-model
Additional headers: (none)
```

ค่าการเชื่อมต่อแบบกำหนดเองรวมอยู่ในการสำรองและกู้คืนข้อมูล การส่งคำตอบแบบต่อเนื่อง การเรียกเครื่องมือ และการรับภาพขึ้นกับความสามารถและความเข้ากันได้กับ OpenAI ของเซิร์ฟเวอร์และโมเดล
