# Vyact Community Roadmap

This roadmap describes the public community infrastructure planned for Vyact. It is directional rather than a promise of exact delivery dates. Progress and scope changes will be tracked through public issues and pull requests.

## Goals

- Give users a searchable place to ask questions and share workflows.
- Help contributors collaborate across languages and time zones.
- Turn resolved support discussions into reusable technical knowledge.
- Provide safe, transparent moderation and privacy controls.
- Publish reproducible infrastructure and operating documentation.

## Phase 1 — Foundation (Months 1–3)

- Define community data, privacy, retention, and moderation policies.
- Implement accounts, profiles, categories, posts, comments, and reporting.
- Store attachments separately from application instances.
- Add automated tests, deployment automation, backups, and cost monitoring.
- Run a small invitation-based test with contributors and early users.

## Phase 2 — Public Beta (Months 4–6)

- Launch the public discussion board.
- Add real-time community chat with presence and rate limiting.
- Add full-text search for discussions and documentation.
- Publish contributor onboarding and moderator procedures.
- Measure availability, search quality, response time, and community safety.

## Phase 3 — Searchable Community Knowledge (Months 7–9)

- Add semantic and hybrid search for resolved questions.
- Allow accepted answers and curated community knowledge.
- Add multilingual metadata and improve internationalized moderation flows.
- Evaluate retrieval quality with a documented, privacy-safe test set.

## Phase 4 — Sustainability (Months 10–12)

- Review usage, infrastructure cost, retention, and moderation outcomes.
- Scale only the components justified by measured demand.
- Document backup restoration and incident-response exercises.
- Recruit reviewers and additional maintainers from sustained contributors.
- Publish a summary of community outcomes and the following year's plan.

## Success Measures

The project will report aggregate, privacy-preserving measures such as:

- Monthly active community participants
- Questions receiving a useful response
- Median time to first response
- Search success and zero-result rates
- Documentation improvements created from recurring questions
- New contributors, reviewers, and maintainers
- Service availability and monthly infrastructure cost
- Moderation reports and resolution time, without exposing personal data

Targets will be set after the invitation-based test establishes a realistic baseline. Vyact will not invent adoption numbers in funding applications or public reports.

## Participation

Feature proposals, accessibility feedback, translations, deployment reviews, and moderation-policy feedback are welcome through GitHub issues. See [CONTRIBUTING.md](CONTRIBUTING.md) and [GOVERNANCE.md](GOVERNANCE.md).
