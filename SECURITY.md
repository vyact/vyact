# Security Policy

## Supported Versions

Vyact is under active development.

Please use the latest released version before reporting a security issue.

## Reporting a Vulnerability

If you discover a security vulnerability, please **do not create a public GitHub issue**.

Instead, report it privately by email:

**vyactagent@gmail.com**

Please include:

- A description of the issue
- Steps to reproduce
- Potential impact
- Any proof-of-concept (if available)

We will investigate the report as quickly as possible and work with you to resolve the issue before public disclosure.

Thank you for helping keep Vyact secure.
