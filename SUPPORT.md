# Support

## Getting Help

For installation, usage, or configuration questions, please start with the [README](README.md) and [building guide](BUILDING.md).

If you still need help, open a GitHub issue with enough context to reproduce the problem, including your operating system, Vyact version, and relevant error messages.

## Feature Ideas and Feedback

Use the Feature Request issue form for product ideas, workflow feedback, and documentation improvements. Please search existing issues before creating a new one.

## Security Issues

Do not report vulnerabilities in public issues. Follow the private reporting process in [SECURITY.md](SECURITY.md).

## Contribution Policy

Vyact is currently maintained by the project owner and is not accepting code contributions. Please open an issue before investing time in a proposed change. See [CONTRIBUTING.md](CONTRIBUTING.md) for details.
